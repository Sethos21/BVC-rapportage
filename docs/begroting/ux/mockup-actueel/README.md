# Actuele interactieve begrotingsmock-up

Dit is de actuele volledig interactieve Work-mock-up van de BVC Begrotingsmodule.

Datum: 2026-10-06

## Lokaal starten

Vereist: Node.js.

Open een terminal in deze map en voer uit:

```bash
npm run dev
```

Open daarna `http://localhost:4173/` in de browser. Het entrypoint is `index.html`.

## Status van deze referentie

Deze mock-up is leidend voor de visuele vormgeving en interactie van de Begrotingsmodule. Het FO en `../../BEGROTING_MASTER_CONTRACT.md` blijven leidend voor financiële en andere businesslogica.

Bedragen, namen en overige demo-data in deze mock-up zijn uitsluitend demonstratiegegevens en gelden niet als productiegegevens.
