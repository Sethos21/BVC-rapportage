# Legacy prototype (archief)

Dit is de oorspronkelijke single-file HTML-prototype van BVC Rapportage
(`index.html`, client-side, geen backend, geen database). De tool wordt
herbouwd volgens het overdrachtsdossier `Vastgoed-AI_Architectuur_v2.0`
op een relationele (PostgreSQL) datalaag — zie de root-README voor de
nieuwe structuur.

Deze map blijft bewaard als functionele/visuele referentie en omdat het
foutdossier (`10_FOUT_EN_ACCEPTATIEDOSSIER_v0.3.md` in het dossier)
concrete fouten in dit prototype beschrijft die de herbouw moet
voorkomen (bv. hardcoded bankstreefwaarde, `Math.abs()` voor
balansclassificatie, verborgen servicekostencategorisatie). De code
hier wordt niet meer actief doorontwikkeld.
